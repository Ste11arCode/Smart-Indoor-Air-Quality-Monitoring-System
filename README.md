# Smart Indoor Air Quality Monitoring System

An IoT-based indoor air quality monitoring system built using:

- ESP32
- DHT22
- MQ135
- ThingSpeak
- Streamlit
- Plotly

## Features

- Real-time monitoring
- Historical trend graphs
- Overall room health assessment
- Air quality recommendations
- Automatic cloud synchronization

## Dashboard

The dashboard is deployed using Streamlit Community Cloud.
